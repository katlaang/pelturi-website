# Assets

Place your icon and splash images here:

- icon.png          — 1024×1024  app icon
- splash-icon.png   — 1284×2778  splash screen
- adaptive-icon.png — 1024×1024  Android adaptive icon foreground
- favicon.png       — 32×32      web favicon

Expo will use these automatically based on app.json references.
You can generate all sizes from a single 1024×1024 image using:
  npx expo-optimize  (or use https://icon.kitchen)
